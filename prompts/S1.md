## Prompt 1: scheme-dev skill file

I am working on an assignment for Principles of Programming Languages that allows the use of generative AI. Please write one skill file: skills/scheme-dev/SKILL.md.

A skill file is a reusable instruction pack for an AI assistant. It must begin with a YAML header containing name (scheme-dev) and description, followed by instructions in Markdown.

The skill file is for writing Racket 8.x code in #lang racket/base for two problems: binary tree traversals (printing inorder, preorder, postorder, height and leaf count) and conditionally inserting an element into every short list of a nested list. The Scheme code may only use these built-ins: define, lambda, let, let*, letrec, named let, if, cond (with else), and, or, not, begin, quote, cons, car, cdr, list, every composition of car and cdr up to four levels, null?, pair?, eq?, assq, assoc, the arithmetic and comparison operators + - * < > <= >= =, max, display and newline (read is allowed only in the second problem). Forbidden: set! and relatives, vectors, hash tables, strings, loops (do, for), and length, append, reverse, map, filter, member, memq, list-ref, list-tail. If a helper is needed it must be written by hand (for example my-reverse).

It must contain these sections:

1. Language and version: Racket 8.x, #lang racket/base, and the allowed and forbidden built-ins.
2. Coding conventions: kebab-case names, a short comment above every function giving its recursive reading, passing state through arguments, preferring tail recursion, small helpers.
3. File rules: files contain only definitions, nothing is called or printed at top level or when the file is loaded, output uses display and newline only.
4. How to run and test: racket FILE.rkt, and how to test by joining a separate test-calls file to the solution file, including testing with standard input.
5. Self-review checklist the AI must apply before answering, as a numbered list.
6. Known failure modes of AI tools when writing Scheme or Racket, such as using forbidden built-ins out of habit, using unlisted helpers like equal? or when, using #lang racket, printing wrongly, leaving test calls at top level, wrong tree conventions, treating the empty list as an atom, and mutation.

Keep it practical and under about 100 lines. Return only the contents of the file.
